# Cold email guidelines (Step 6)

## Eligibility

- Send only to addresses recorded in the sheet with a source (post URL or posting).
- One email per company and role. Never email the same address twice in a session.
- Send from the account the user chose in Step 1 and put that address in the signature.

## Content rules

- Under 150 words.
- CV facts only: no invented years, skills, links or results.
- Plain tone: no flattery, no buzzword stacking.
- Include: role and where it was seen, one specific match with a real project, links, logistics, signature.
- Student or fresher: state the graduation year.

## Attachment workflow

1. Try to attach the chosen resume to the draft.
2. If the environment cannot pass the file, ask the user to attach it in Gmail.
3. After the user says they attached it, fetch the raw draft and parse the MIME parts. Confirm a filename and size.
4. Never send text that says "resume attached" without a verified attachment.
5. Do not edit a draft after the user has attached a file. An update can strip attachments.

## Sending

Send only after the user says "send". Afterwards report the recipient and the attachment filename.

## Follow-ups

Offer at most one follow-up, after 7 days with no reply, and only if the user asks. Use templates/follow-up-email.md.

## Bounces

If an address bounces or is rejected, mark it in the sheet. Do not try variants or pattern-built addresses.
