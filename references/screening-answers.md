# Screening questions in Easy Apply (Step 5)

Answers come from Step 1 replies and the CV. If a needed fact is missing, stop and ask the user. Never guess.

| Question type | How to answer |
|---|---|
| Years of experience with a skill | Use the CV-based number from the profile. Do not round up |
| Current CTC / expected CTC | Exactly what the user gave in Step 1 |
| Notice period / joining date | What the user gave |
| Willing to relocate / commute / work hybrid | Step 1 answer only |
| Work authorisation | Step 1 answer only; if not collected, ask |
| English proficiency | Ask the user if the CV does not state it |
| Free-text "why this role" | Two or three honest sentences using CV facts and the posting |
| Diversity, disability, gender, ethnicity | "Prefer not to say" unless the user said otherwise |
| Links (GitHub, portfolio) | Only links on the CV |

## Review page checklist

- Phone and email match the CV
- Resume is the one LinkedIn pre-selected, unless the user named another
- "Follow company" is unticked
- No upsell (Premium, alerts) accepted
- Submit only if the user approved this batch

## After submission

Confirm the success screen. Update the sheet status to Applied and append to the running list of submissions.

## When to stop

- A form fails or loops twice: note it in the sheet and move on
- "Apply" opens an external site that needs an account: hand it to the user and offer to draft answers
