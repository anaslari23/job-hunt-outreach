# LinkedIn verification (Step 3)

Every Instagram-listed opening gets a LinkedIn result recorded. No sampling.

## Search pattern

1. Query: `<company> <role title>`, location set to the user's country.
2. If nothing: query the company name alone and scan its jobs.
3. If still nothing: label "Not found", not "closed". Small firms often hire by email only.

## Capture per posting

- Exact title, city, work mode (on-site, hybrid, remote)
- Posted how long ago
- Stated experience requirement (this often differs from Instagram)
- Easy Apply or external Apply
- Applicant count if shown
- Company careers link and HR email, only if visible on the page

## Status labels

| Label | Meaning |
|---|---|
| Live | Same title is posted |
| Similar role live | A close title is posted at the same company |
| Not found | Two searches found nothing |
| Too senior | Requirement is more than one year above the user's |
| Not verifiable | Instagram post had no company name |

## Fit labels

| Label | Rule |
|---|---|
| Strong | Experience in range, at least half the key skills match, location works |
| Stretch | One year or more above, or a key skill is missing but learnable. State the gap |
| Poor match | Different core stack |
| Not a fit | More than one year above, wrong field, or wrong location with no remote option |

## Prioritising

Rank Strong roles first. Within a fit label, prefer posted within 7 days and under 100 applicants.

## Requirements check tab

For each shortlisted role, write one row: their requirement, the user's matching profile line, the verdict, and a one-sentence reason. Quote the CV, not an impression.

## Constraints

- LinkedIn does not show recruiter emails. Never guess one, never use paid lookup tools.
- If a page script is blocked because the URL has tracking parameters, use page text or a screenshot, or open the clean URL.
- Filter result cards by company name in scripts and return short text only.
