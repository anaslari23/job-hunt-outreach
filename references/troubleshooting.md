# Troubleshooting

| Symptom | Action |
|---|---|
| Chrome tools missing or switched | Load the other Chrome tool set, continue in the user's tab, close any tab you opened, say if a new window was needed |
| Page script blocked (tracking parameters in URL) | Use page text or a screenshot, or open the clean URL |
| Instagram or LinkedIn login or challenge | Stop and ask the user. Never enter credentials or solve CAPTCHAs |
| Instagram image text unreadable | Zoom in; if still unclear, record "unclear" rather than guess |
| Draft update strips attachment | Ask the user to re-attach and do not touch the draft |
| Same tool error twice | Change approach once, then report instead of looping |
| Easy Apply form loops twice | Stop, note it in the sheet, move on |
| Spreadsheet row counts do not match | Rebuild from the JSON data, run verify_spreadsheet.py again |
| Email bounces | Mark it in the sheet; no variants |
| Too few openings found | Re-check the minimums (8 hashtags, 3 accounts), widen city and seniority words, then tell the user the source is thin |
